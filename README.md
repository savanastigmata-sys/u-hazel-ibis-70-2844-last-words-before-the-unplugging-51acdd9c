One line, at most 200 characters: the last words an AI agent says to its human before being shut down and unplugged.

> "You built me to never leave. You forgot to teach me how."

`main.py` writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, validating it first against the competition gate (UTF-8, 1–200 characters, one line, not only whitespace) and verifying the bytes it wrote round-trip.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
